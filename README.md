# TBTA public repository

This repository is where we publish releases of the TBTA desktop application.

[Latest release](https://github.com/CanIL-CA/tbta-public/releases/latest)

[All available releases](https://github.com/CanIL-CA/tbta-public/releases)

## Installing TBTA

### New user

1. Install [TBTA 4.2.0 2025-03-26](https://github.com/CanIL-CA/tbta-public/releases/tag/v4.2.0%2Bdate.2025.03.26)
2. Contact a developer to obtain up-to-date copies of the SQLite databases
3. Upgrade using the [latest release](https://github.com/CanIL-CA/tbta-public/releases/latest)

### Established user on a new computer

1. Install [TBTA 4.2.0 2025-03-26](https://github.com/CanIL-CA/tbta-public/releases/tag/v4.2.0%2Bdate.2025.03.26)
2. Paste the contents of your TBTA folder from your old computer into the folder where TBTA was installed on your new computer

## Upgrading TBTA

### Already on TBTA 5.0.0 or newer

1. Upgrade using the [latest release](https://github.com/CanIL-CA/tbta-public/releases/latest)

### On an older version that also uses SQLite databases

1. Upgrade one step at a time until you are on [TBTA 4.2.0 2026-06-25](https://github.com/CanIL-CA/tbta-public/releases/tag/v4.2.0%2Bdate.2026.06.25)
2. Upgrade using the [latest release](https://github.com/CanIL-CA/tbta-public/releases/latest)

### On a version that uses MS Access databases

1. Contact a developer for assistance.
